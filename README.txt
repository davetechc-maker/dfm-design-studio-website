PUBLISHING:
Upload the CONTENTS of this folder (index.html and assets folder) to the root of the GitHub repository named dfm-design-studio-website.
Do not upload the ZIP file itself as the website root.
If using GitHub on Android: open the repository > Add file > Upload files > select index.html and the assets folder contents. For easier bulk upload, extract this ZIP on your phone first.
Then connect the repository to Vercel and deploy. Do not change DNS until the preview is checked.
